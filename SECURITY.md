# Security

The hooks in this repository are examples, not complete security products.

Do not report bypasses of example hooks as vulnerabilities unless they expose secrets or create risk in this repository itself.

For production use, adapt, test, and combine these examples with maintained scanners, sandboxing, review, approval policy, and CI verification.

If you believe this repository itself exposes a secret, unsafe workflow, or security-sensitive defect, open a private report through GitHub Security Advisories when available, or contact the maintainer directly.
